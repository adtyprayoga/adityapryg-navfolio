Aplikasi pengelolaan buku: membuat, membaca, memperbarui, dan menghapus data
buku, dengan autentikasi serta beberapa peran pengguna yang mengatur apa yang
bisa dijangkau tiap akun.

Saya membangunnya dengan **Laravel** dan template engine **Blade**. Repositorinya
berada di bawah materi software testing fundamentals, jadi aplikasi ini sekaligus
jadi bahan untuk menulis pengujian.
