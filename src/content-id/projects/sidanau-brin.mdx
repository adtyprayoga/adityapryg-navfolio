**Tech Lead at BraindevsID · 2023 · BRIN**

A national lake information platform. I led the build, pulling lake datasets
that sat scattered across agencies into one place so agencies plan conservation
from the same evidence.

Laravel for the backend and data services, Next.js for the public portal, REST API for integrations with flutter mobile app (other team build it), 
PostgreSQL underneath.
