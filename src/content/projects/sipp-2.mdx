Modernized legacy personnel data management into a single platform: centralized
records, advanced search, access-controlled sign-in, and self-service document
workflows that moved routine requests off manual handling.

Built with Laravel, Next.js, and PostgreSQL, with query and index work to keep
the search paths responsive at scale.

The work was recognized with the Kapolri Gold Pin in 2021.
