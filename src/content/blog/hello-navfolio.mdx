## Writing notes

Add Markdown or MDX files under `src/content/blog/`. Each file needs at least a
`title`, a `description`, and a `date` in its frontmatter. Optional fields
include `tags`, `categories`, `series`, `draft`, and `sticky`.

## Changing the interface language

The UI language lives in `src/config/site.toml`:

```toml
[config.theme]
lang = "en" # en (default), id, zh-CN, zh-TW
```

Set it to `id` for Indonesian.
